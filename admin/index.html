MEYTOPIA Régie

Le panneau d'administration du launcher. Maintenance, événements, actualités, couleurs : chaque action est publiée vers tous les joueurs en ~5 minutes.

Comment obtenir un jeton ?
  1. Ton compte doit être collaborateur du dépôt meytopia-data — c'est Alexis qui invite.
  2. Compte de service Meytopia (Admin-…) : Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
  3. Note « Regie Meytopia », expiration 90 jours, coche uniquement la case repo, puis Generate. (GitHub ne propose pas les jetons fine-grained aux collaborateurs d'un dépôt personnel ; ce compte n'ayant accès qu'à meytopia-data, la portée revient au même.)
  4. Compte personnel avec d'autres dépôts : préfère un Fine-grained token → Only select repositories → meytopia-data → Permissions → Contents : Read and write.
  5. Colle le jeton ici. Il ne quitte jamais ton navigateur (envoyé uniquement à api.github.com).

Ajoute, met à jour ou remplace des mods par lien (direct ou CurseForge), plusieurs d'un coup (un par ligne) — GitHub assemble et publie tout seul, sans PC. Laisse Simulation coché pour un essai sans rien publier.

🏁 Nouvelle saison
À utiliser quand tu changes de saison : archive (ou non) la saison en cours puis remet toutes les statistiques à zéro côté GitHub uniquement — ce bouton ne touche à aucun fichier de ton serveur (panel OuiHeberg) : le vidage du panel, c'est toi qui le fais, comme d'habitude. Ordre conseillé : ① éteindre le serveur → ② ce bouton → ③ vider le panel → ④ réinstaller le serveur neuf + le mod sonde (jar dans mods/) et sa config avec le jeton (config/meytopia_sonde.toml) → ⑤ démarrer : la sonde repart sur la nouvelle saison vide.
🗑️ Retirer un joueur des archives (droit à l'effacement)
Si un joueur demande à disparaître (RGPD), ce bouton efface son pseudo, son identifiant (UUID), ses horaires et ses récompenses de toutes les archives : « L'histoire des saisons » (seasons/, publique) ET les sauvegardes quotidiennes de la sonde (dépôt privé meytopia-backups, visible de toi seul) — un commit tout-ou-rien par dépôt. Les totaux communautaires anonymes (barres de défis, cumuls) et les stats des autres joueurs sont conservés : rien ne casse pour le reste de la communauté. ⚠️ Pour la saison en cours, c'est au joueur de taper /meyprivacy cacher en jeu (effet immédiat sur les pages publiques) — ce bouton ne touche pas au fichier vivant de la sonde, qui le réécrirait par-dessus. Ordre conseillé si le joueur joue encore : d'abord /meyprivacy cacher, PUIS ce bouton — sinon, tant qu'il reste public, la sauvegarde quotidienne suivante de la sonde le mentionnera à nouveau (dans le dépôt privé).

Téléchargements

Téléchargements publics des releases GitHub — le pouls de la distribution du launcher et du pack.

Comment lire ces chiffres
Installeurs
Téléchargements de l'installateur de cette version — chaque unité ≈ une nouvelle installation (ou réinstallation) du launcher.
Contrôles de MAJ
Combien de fois des launchers déjà installés ont demandé « y a-t-il du neuf ? » pendant que cette version était la dernière. C'est l'activité des launchers ouverts — pas un nombre de joueurs.
Modpack — Fichiers / Téléchargements
« Fichiers » = le contenu du pack ; « Téléchargements » = fichiers servis aux launchers (installations et réparations). Téléchargements ÷ Fichiers ≈ nombre d'installations complètes du pack.
